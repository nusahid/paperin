Paperin v0.2.0 adds page rearrangement and image conversion to the offline PDF workspace for Windows x64.

## What's new

- **Rearrange PDF pages:** drag one page or a selection, reverse the current order, undo/redo, reset, and preview before saving a new PDF. Page content is preserved without rasterizing it.
- **Keyboard page organization:** select ranges, select all, move a selection with Alt+Arrow, and undo/redo from the thumbnail grid.
- **Large-document thumbnails:** the Rearrange grid uses virtualization and a bounded thumbnail cache, with offline testing on a 1,000-page document.
- **Image to PDF:** combine JPG/PNG files, arrange and rotate images, and choose page size, orientation, fitting, and margins.
- **PDF to Image:** export selected pages or ranges as JPG/PNG, with resolution, preview, progress, and cancellation controls.
- **Safer exports:** Rearrange validates the complete page order, protects source files, supports cancellation, and offers Keep Both, Replace, or Cancel for existing destinations.
- **Reader fix:** thumbnails are disabled while another PDF is loading so page selection applies to the document being opened.

## Download and installation

1. Download **Paperin-Setup.exe** from Assets below.
2. Close an older Paperin instance, then run the installer.
3. Open Paperin from the Start Menu and check that the sidebar shows **v0.2.0**.

Node.js, npm, and qpdf do not need to be installed separately. The installer includes the required runtime and local PDF engine. Once installed, all document processing works offline.

The installer is **unsigned**. Windows SmartScreen may display an unknown-publisher warning. See the [installation guide](https://github.com/nusahid/paperin/blob/v0.2.0/docs/INSTALLATION.md) for download verification and installation details. **SHA256SUMS.txt** contains the installer checksum.

## Compatibility and limitations

- Windows x64 only; PDF imports are limited to 512 MB each.
- Rearrange blocks digital signatures and signature fields. Protected PDFs require a valid password and permission to assemble pages; output encryption is retained.
- Review bookmarks, custom page labels, links, and interactive forms after page operations.
- PDF to Image produces raster images and does not preserve selectable text or document navigation.
- Added signature images are visual marks, not certificate-based digital signatures.
- OCR, automatic updates, and persistent editing sessions are not available.
- Clean Windows installation certification and reference-hardware performance benchmarks remain pending.
